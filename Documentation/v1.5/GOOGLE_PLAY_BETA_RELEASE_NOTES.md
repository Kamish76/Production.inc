# Production.INC - Version 1.5.0 Beta Release Notes
**Google Play Console - Internal/Beta Testing**

---

## 🎮 What's New in Version 1.5.0

### 🤖 AUTOMATION SYSTEM - THE BIGGEST UPDATE YET!

**Auto-Buy Machines**
Let your factory run on autopilot! Six Auto-Buy machines automatically purchase raw materials when you're low, so you can focus on strategy instead of clicking "Buy" repeatedly.
- Configure capacity limits (10-100 units per material)
- Real-time countdown timers
- Smart money management - won't overspend
- Enable/disable anytime

**Auto-Build Machines**
Watch your production lines work automatically! Three-tier Auto-Build system produces items from basic parts to complex retail products.
- Tier 1: Basic Parts (Box, Wires, Circuits, etc.)
- Tier 2: Intermediate Components (Processor, Display, Camera, etc.)
- Tier 3: Complex & Retail (Smartphones, Solar Panels, etc.)
- Adjustable speed: 1x to 100x multipliers
- Live production tracking per tier

**New Control Screen**
All automation controls in one place! Redesigned Control Center with:
- Easy machine management interface
- Toggle between Machines and Tiers sections
- Quick access to settings
- Smooth animations and intuitive layout

## 🐛 Bug Fixes

### Critical Fixes
- **Fixed**: Material leak in auto-build system (materials were disappearing during automated production)
- **Fixed**: Newly unlocked items not appearing in Build screen
- **Fixed**: Automation not triggering unlock system for new products
- **Fixed**: Duplicate ID generation causing save/load issues
- **Fixed**: Production speed exploit with very high multipliers

### UI/UX Improvements
- Better visual feedback for machine status
- Real-time production progress indicators
- Improved navigation and screen organization
- Enhanced error handling and recovery

## ⚠️ Known Issues & Limitations

### Expected Behavior
- **Minimum Build Time**: All auto-build items have 1-second minimum (prevents instant production)
- **Money Constraints**: Auto-buy stops when insufficient funds (this is intentional)
- **Material Priority**: Auto-buy purchases cheapest materials first
- **Dev Controls Visible**: Developer tools are visible in Tiers section (for testing purposes)

### Future Features (Not in This Build)
- Tier system (placeholder visible but not functional)
