# Sprint 1: Legacy Foundation & Early Development (v1.0 – v1.4)

> **Timeline**: August 2025 & Earlier  
> **Status**: Archived Historical Sprint

---

## 🎯 Overview
This directory preserves the foundational game design documentation, original design philosophies, economic balance sheets, and incremental version logs from the early development of **Production.Inc** (v1.0 through v1.4.19).

---

## 📁 Archived Files & Specifications

### 💡 Game Concept & Design
- **[`Concept.txt`](Concept.txt)**: Original high-level pitch, core gameplay loops, user experience vision, and early tier planning.
- **[`game economy.txt`](game%20economy.txt)**: Comprehensive calculations for material costs, crafting requirements, base profits, time-to-produce balance, and price scaling formulas.
- **[`Store listing.txt`](Store%20listing.txt)**: Early marketing copy, short descriptions, and feature bullet points prepared for the Google Play Store.

### 📜 Version History & Logs
- **[`release_notes/releasenotes`](release_notes/releasenotes)**: Early user-facing release notes across patch updates.
- **[`version_documentation/`](version_documentation/)**: Detailed developer logs tracking features added per minor version:
  - **[`version_documentation/README.txt`](version_documentation/README.txt)**: Index of early version notes.
  - **[`version_documentation/v1.2.txt`](version_documentation/v1.2.txt)**: Version 1.2 milestones.
  - **[`version_documentation/v1.3.txt`](version_documentation/v1.3.txt)**: Version 1.3 features and expansions.
  - **[`version_documentation/v1.4.txt`](version_documentation/v1.4.txt)**: Version 1.4 master changelog and comprehensive phase tracking.
  - **[`version_documentation/1.5.txt`](version_documentation/1.5.txt)**: Early draft roadmap and thoughts for v1.5.
  - **[`version_documentation/concept_and_future.txt`](version_documentation/concept_and_future.txt)**: Early conceptual notes on automation, prestige, and logistics.
